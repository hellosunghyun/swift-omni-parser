## 최종 교체 판정

1. OPEN 항목의 구현을 보완하고 샘플 정답과 회귀 테스트를 추가한다. 경고만 추가해 기능 보존으로 처리하지 않는다.
2. Ream 경로를 실제 parse/parseBatch에 연결한 별도 구성에서 기존 모든 형식을 재실행한다.
3. 같은 실기기에서 대용량·혼합 배치·취소·메모리·시간을 측정하고 전체 결과 fingerprint를 비교한다.
4. 모든 기준이 충족된 뒤 기존 Office 의존성을 제거한 앱의 크기를 측정하고 생산 반영 여부를 결정한다. 최초 점검에서는 이 단계에 도달하지 않았다. 후속 실험의 실제 앱 측정과 미완료 항목은 위 링크에 구분했다.

실행 명령·샘플·로그는 [iOS 실험 보고서](REAM_IOS_EXPERIMENT.md)를 참고한다. 외부 샘플 추가는 출처·라이선스 확인 후 진행하며 이번에는 기존 문서와 코드로 생성한 PPT fixture만 사용했다.
