2026년 10월 26일, Xcode 27.1 / Apple Swift 6.4 환경에서 확인했습니다. Swift 언어 모드는 5.0입니다.

| 확인 항목 | 결과 |
| --- | --- |
| Package.swift 해석 | 통과 |
| iOS Simulator 일반 빌드 | 통과, arm64·x86_64 |
| 기기용 iOS 일반 빌드 | 통과, arm64, 서명 생략. 실기기 실행 아님 |
| SwiftLint strict | 통과, 위반 0개 |
| 직접 의존성의 고정 커밋 LICENSE 대조 | 다섯 항목 일치 |
| 포함 OfficeOxide 정적 아카이브 SHA-256 대조 | 두 아카이브 모두 통과 |
| 새 패키지에서의 형식별 추출 회귀 테스트 | 실행하지 않음 |
| 새 패키지에서의 실기기 실행·성능·메모리 | 실행하지 않음 |

테스트 타깃·샘플은 분리 직전 스택에서 이미 제외된 상태를 유지했습니다. 이전 앱 저장소의 테스트 결과를 이 패키지의 새로운 실행 결과로 표시하지 않습니다.
